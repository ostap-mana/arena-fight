# Invokers → панель аналітики: звіт про підключення

**Коротко:** SDK `telemetry.js` (0.3.0) підключено в гру Invokers за кроками 2–4 інструкції. Гра відправляє всі події. **Сервер поки відхиляє дані:** на адресу гри `http://localhost:5173` відповідає `403 {"ok":false,"error":"origin"}`. Прохання додати цю адресу для проєкту `invokers`.

## Крок 1. Блок для сервера

```
ПРОЄКТ:        invokers
АДРЕСА ГРИ:    http://localhost:5173
ПРЕВ'Ю-АДРЕСИ: нема
НАЗВА ГРИ:     Invokers Titan Legacy
ВАРІАНТИ:      нема (для перевірки — test)
КОНТАКТ:       ostap@mana.is
```

Гра запускається локально (`npm run dev`), тому адреса — `localhost`. Якщо гратимемо з телефона в тій самій Wi-Fi мережі, знадобиться ще адреса виду `http://192.168.x.x:5173` — допишу, коли буде.

## Що відправляє гра

| момент у грі | виклик SDK |
|---|---|
| з'явився екран вибору героя (перший кадр гри) | `gameReady()` + `performance.mark('boot.firstFrame')` |
| перший тап/клік | `firstInput()` |
| почався бій | `runStart()` |
| перемога над босом / смерть героя | `runEnd({ result: 'win' / 'lose', stats })` |
| «Ще раз» (на екрані поразки й на ендкарді) | `retryClicked()` → новий `runStart()` |
| CTA (PLAY NOW, кнопки сторів) | `ctaClicked()` — до переходу в стор |
| закрили вкладку посеред бою | `quit` зі статистикою (через `setPartialProvider`) |

**`stats` у кожному забігу (усі числа):**

| поле | значення |
|---|---|
| `hero` | 0 = Confar, 1 = Ardell, 2 = Ricklow |
| `wave` | до якої хвилі дійшов (1…) |
| `kills` | убито монстрів |
| `power` | сила героя з урахуванням спорядження (ціль 10 000) |
| `titan` | 1, якщо забіг закінчився у формі титана |

**Продуктивність:** `setRendererInfo(() => renderer.info)`, `setGl(renderer.getContext())`, а також фази завантаження як `performance.measure`:

| фаза | що це |
|---|---|
| `boot.module` | код гри завантажено й запущено |
| `boot.models` | арена й моделі героїв для лобі |
| `boot.audio` | звук і шрифти |
| `boot.loop` | старт рендер-циклу |
| `boot.compiled` | шейдери скомпільовано |
| `boot.warm` | текстури й перший прогрів кадру |
| `boot.select` | показано екран вибору героя |

**Мітки сесії:**
- `project`: `invokers`;
- `src`: з `?src=`, а без нього на локальному сервері — `local`;
- `v`: з `?v=`, інакше `default`;
- `build`: `dev` на локальному сервері, `<git sha>.<хеш збірки>` у тест-збірці.

## Збірки

- `npm run dev` і `npm run build:test` → SDK увімкнено.
- Рекламні збірки (`npm run build`, `npm run single` → один html для мереж) → SDK вирізається повністю. Перевірено: у зібраних файлах 0 входжень `api/ingest`, 0 зовнішніх запитів.

## Перевірка (крок 5)

Сесія `http://localhost:5173/?v=test&src=dev`, один бій до перемоги:
- гра відправила події `session_start`, `game_ready`, `first_input`, `run_start`, `run_end` і забіг із `perf`, помилок у грі нема;
- усі 6 запитів на `/api/ingest` відхилено, тож у панелі цієї сесії ще нема. Сервер відповідає **403 `{"error":"origin"}`** (перевірено напряму з `Origin: http://localhost:5173`). Відповідь 403 приходить без CORS-заголовків, тому в DevTools це видно як `net::ERR_FAILED` / CORS error, а не як 403;
- SDK вважає таку відмову збоєм мережі: тримає конверти в outbox (до 3 днів) і дошле, коли адресу додадуть.

Окремо, з підміненим сервером, перевірено вміст конвертів: перемога, `quit` посеред бою і `retry` приходять зі `stats`, `perf` (fps, p95, ривки) і фазами `boot.*`.

## Відступи від інструкції

- **Старт SDK — коли завантажився код гри, а не до ассетів.** Гра починає качати моделі ще з `index.html`. Тож гравці, які пішли в перші секунди, поки вантажиться JS, у тест-збірці не потраплять у панель. На localhost це не важить; якщо треба, SDK можна перенести в `index.html`.
- Плівки забігів (`tape`/`trace`) не відправляються: за інструкцією вони не потрібні.

## Файли в проєкті

- `src/net/telemetry.js` — SDK без змін;
- `src/net/track.js` — ініціалізація й обгортки викликів (вмикається тільки в dev і test-збірці);
- `src/core/game.js`, `src/net/bus.js` — виклики в потрібних місцях гри;
- `package.json` — скрипти `build:test` (→ `dist-test/`) і `dev:test`.
